# PIM TerraTrace

React + TypeScript + Vite + Tailwind CSS.

## Desenvolvimento

```sh
npm install
npm run dev
```

No PowerShell com scripts desabilitados, use `npm.cmd` no lugar de `npm`.

## Verificação

```sh
npm run lint
npm run build
npm run preview
```

O build é gerado em `dist/`.

- `src/App.tsx`: componente inicial.
- `src/main.tsx`: entrada da aplicação.
- `src/index.css`: Tailwind e estilos globais.
- `vite.config.ts`: plugins React e Tailwind.

Tailwind configurado com a integração oficial `@tailwindcss/vite`.
